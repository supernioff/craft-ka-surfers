# Craft Ka Surfers

A 3D endless runner set on underground cave railway tracks. Dash down the track, dodge runaway TNT minecarts and hurdles, collect diamonds, and outrun the Inspector.

**Play it live:** https://craft-ka-surfers.vercel.app/

## Features
- 3D endless runner gameplay
- Different cave themes
- Costumes for the runner character
- Leaderboard
- Guest play, no login needed
- 1v1 multiplayer races
- Aerial phantom obstacle and dive move
